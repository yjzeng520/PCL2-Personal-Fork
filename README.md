# PCL2 Personal Fork

An unofficial, non-commercial personal fork of **Plain Craft Launcher 2 (PCL2)**.

## Project Overview

This project is based on the open-source Minecraft launcher Plain Craft Launcher 2.

It is maintained independently for personal learning, software development, and testing.

The main development goals include:

- Learning about Minecraft launcher architecture.
- Integrating the official CurseForge API.
- Supporting Minecraft mod and modpack discovery.
- Retrieving mod information and compatible versions.
- Testing authorized mod downloads through the CurseForge API.
- Improving personal development and debugging experience.

## CurseForge API Integration

This project aims to integrate CurseForge API functionality using an officially authorized API key.

All API requests and downloads will comply with CurseForge's API Terms of Service and mod authors' permissions.

API credentials will not be publicly shared or committed to the repository.
